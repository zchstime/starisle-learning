# 星宝 · Blender 外形初稿

依据 `docs/character-design/approved/xingbao-approved.png` 的已认可瘦脸形象制作。这里的预览由 Blender 实际模型渲染，不是概念图。

## 文件

- `xingbao-sculpt-v2.blend`：可编辑源文件，含角色独立部件、材质、摄影棚灯光与相机。
- `xingbao-sculpt-v2.glb`：自包含模型导出，仅含角色，不含摄影棚。
- `../../previews/xingbao-v2/`：正面、四分之三视角、侧面及背面实际渲染。
- `../../tools/model-xingbao.py`：可重复生成模型及预览的脚本（Blender 5.2）。
- `export-validation.json`：GLB 结构与模型规模检查结果。

## 当前完成

非对称卷曲头顶、蓝色眼睛及高光、嘴部、脸颊、身体、四肢、双层披风、金色镶边、星星装饰、独立提灯组件。部件分开命名，便于进一步修改及绑定。

## 尚未完成

这是外形初稿，不是最终游戏角色。与已认可概念图仍有差距：卷尖偏厚，衣领和披风较硬，眼睛较凸，尚缺织物与绒毛细节。需要继续精修轮廓及表情。

尚无骨骼、蒙皮、眨眼或动作动画。当前为高面数预览模型，进入移动端前需拓扑简化、贴图烘焙及性能验证。本轮没有替换游戏内角色，也没有修改玩家进度。

## 后续制作顺序

1. 对照定稿图精修头部、衣领、手脚及眼球嵌入深度。
2. 制作游戏用拓扑与材质贴图。
3. 绑定身体、手臂、披风与提灯，并制作待机、挥手、跳跃和庆祝动作。
4. 在 Cocos 中检查灯光、透明背景、动作切换及移动端性能，再接入游戏。
