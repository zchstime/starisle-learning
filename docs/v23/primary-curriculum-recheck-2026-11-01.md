# 小学课程与题型复核（2026-11-01）

## 结论

当前内容仍不能表述为“已完整结合小学教材设计”。它已经具备 1～6 年级、11 个学科的可玩路线，并在数学、三至六年级英语等部分记录了教材主题来源，但课程证据多数只到主题层，不是逐册、逐单元、逐课时和逐项学习目标的完整映射。

本轮不扩大教材覆盖声明，重点修正了题型结构：新增可实际作答的配对/连线玩法，并把它接入学习路线、期末试炼、动态内容校验和后台题库导入。非数学、非英语试卷增加自动门禁：每张试卷选择题不得超过一半。

## 当前教材结合程度

| 学科 | 当前状态 | 不能称为完整同步的主要原因 |
| --- | --- | --- |
| 数学 | 12 个主题阶段/年级，主题覆盖相对最好；记录人教社主题来源 | 多数是主题与子技能级，未逐例题、练习层级、综合实践和课时核对；审核状态大多仍为 `draft` |
| 英语 | 三至六年级做过 PEP 主题目录级对应；一二年级明确为启蒙拓展 | 未覆盖完整词汇、语音、对话、阅读、书写与项目任务；需要明确一年级起点/三年级起点及教材版本 |
| 语文 | 按课程标准能力方向设计原创主题 | 未逐册逐课对应统编教材；拼音、写字、朗读背诵、口语交际、整本书阅读、习作与修改仍不完整 |
| 科学、道法、音乐、美术、体育、劳动、信息科技、综合实践 | 按学段能力设计原创任务 | 不同地区教材版本差异大，当前为拓展路线；不能替代实验、创作、运动和劳动实践评价 |

## 本轮题型调整

学习路线共 2201 个可玩任务。调整后的题型分布如下：

| 学科 | 选择题占比 | 其他主要题型 |
| --- | ---: | --- |
| 数学 | 15% | 数字作答、装载、分组、铺格、图片操作 |
| 英语 | 29% | 听音、词卡组句 |
| 语文 | 31% | 词卡组句、事件排序、图片操作、字词/阅读证据配对 |
| 科学 | 33% | 实验步骤排序、图片分类/过程操作、问题—方法配对 |
| 道德与法治 | 42% | 行动排序、图片操作、情境—做法配对 |
| 音乐 | 43% | 听辨、行动排序、图片操作、概念配对 |
| 美术 | 44% | 拼贴铺格、图片操作、行动排序、概念配对 |
| 体育 | 38% | 动作步骤排序、图片操作、情境配对 |
| 劳动 | 35% | 操作步骤排序、图片操作、问题—做法配对 |
| 信息科技 | 38% | 算法/操作排序、图片操作、问题—方法配对 |
| 综合实践 | 38% | 项目步骤排序、图片操作、问题—方法配对 |

期末试炼也已支持配对题。生成器会保留数字作答、排序和配对，并限制非数学、非英语试卷中选择题不超过 50%，避免学习路线已有多种玩法、组卷时却重新退化成选择题。

## 仍然存在的不足

1. **教材真值层不完整**：缺少“教材体系—版次/修订年份—册次—单元—课/小节—核心目标—知识点—学业要求”的完整清单，无法计算真实教材覆盖率。
2. **审核等级不足**：大部分课程仍为 `draft`，尚未完成学科教师逐题审核、儿童试玩和难度数据标定。
3. **题型虽更丰富，但能力闭环仍不够**：语文缺少真实写字、朗读和习作修改；英语缺少多轮口语、拼写和书面表达；数学缺少竖式过程、尺规作图、一题多解与开放题评分。
4. **实践学科不可只靠屏幕评价**：科学实验、体育动作、劳动操作、美术创作和音乐表现必须增加线下实践记录或教师观察，不能用游戏答题分数替代。
5. **试卷蓝图仍是游戏题库蓝图**：当前试炼能控制题型比例，但还未按真实教材的单元权重、领域权重和难度比例建立期中/期末测评蓝图。

## 下一步优先级

1. 锁定实际采用的教材版本与起始年级，先完成一年级语文、二年级数学、三年级英语三个样板册的逐单元映射。
2. 为每个核心知识点至少配置“理解/操作、基础练习、易错诊断、迁移应用”三种以上认知形式，并补足主观表达题。
3. 建立教师审核、歧义检查、答案唯一性、模板重复率、题型比例和难度数据的发布门禁。
4. 真实学生试用后再将 `draft` 升级为 `teacher-reviewed` 或 `pilot-validated`，在此之前继续保留“原创练习、非完整教材覆盖”的产品说明。
