## 年级衔接

- 按当前科目判断：全部本年级关卡完成才可进入下一年级，不要求先做完其他十个学科。
- 直接先玩最后一章不会跳过此前未完成的任务。继续按钮会寻找本年级第一个未完成任务。
- 首次补齐本年级全部任务后，奖励页倒计时 6 秒自动前往下一年级；可点“留在本年级”取消，或立即进入。离开奖励页即停止倒计时。
- 六年级结束后可探索其他科目，不创建七年级；年级与章节可自由返回复习。
- 数学新增第五章，章节列表加入每页四章的翻页控件，已选章节所在页自动定位。

## 奖励与存档

每章完成获得探索勋章，每个年级完成获得该科目远航勋章，六个年级全部完成获得本科目星海纪念章。奖励页加入金色星形绶带勋章；勋章手册显示六个年级的奖章与任务进度。

继续使用 starisle.adventure.v3 存档键与 version 3，新加可选 medals 字段。旧存档按已有完成状态补齐可领取勋章；存档读取过滤未知及重复勋章 ID。奖励不重复累计，已得勋章长期保留；以后追加课程不会撤销已有勋章，但新增任务仍需完成才能满足当前课程的升年级条件。当前是本地学习奖励，不是防作弊认证或掌握程度评定。

## 实现

- ExpansionContent.ts：独立追加内容，避免重排旧 ID。
- Progress.ts：完整年级判定、寻找未完成任务、年级推进及持久勋章。
- Adventure.ts：章节翻页、勋章绘制、奖励衔接与手册。
- tools/test-v2.cjs：扩充可解性、乱序完成、年级边界、勋章持久化与旧存档回归。

## 后续

逐一核对具体人教教材版次与单元映射；优先将科学、劳动、美术选择任务继续改为更具体的动手交互，并增加英语配音与音乐听辨。应由教师及实际儿童试玩检查阅读负担，不能用程序可解性替代教学验收。
