日期：2026-10-30。该单元是课程审计后的第一项内容改造，保持章节和关卡 ID 不变，因此旧存档仍能识别已完成任务。

## 学习目标与边界

目标是理解乘法表示几个相同加数的和，能识别组数与每组数量，并在简单真实情境中选择、计算和解释乘法算式。内容依据项目当前使用的人教版二年级上册主题设计，题目均为原创，不复制教材原题。

该样板只覆盖“等量分组与乘法意义”这一核心概念，不代表二年级整册已经完成逐课同步。后续应根据教师审核结果补入口诊断、隔日复习和同知识点迁移测验，再扩展其他单元。
