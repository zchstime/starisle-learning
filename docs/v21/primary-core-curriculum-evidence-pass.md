## 适用范围与限制

本轮完成的是可诊断、可追踪、可扩展的课程骨架和现有原创任务验收。它能支持后续根据错因推荐练习，但不等于所有题目已经逐页对应当前在校教材，也不应宣传为“学完即可替代学校全部教学”。后续人工教研应按教材版本、册次和单元逐章校对，并补充口语表达、习作批改、开放题评分及真实学生试用数据。

## 下一步教研顺序

1. 先精审语文、英语各年级的一个代表单元，形成可复用的逐课校对模板。

3. 用教师审阅和学生试用数据把 `draft` 升级为 `teacher-reviewed` 或 `pilot-validated`。
