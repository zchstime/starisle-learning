# 各年级题型、重复与分布审计（2026-11-01）

## 审计范围与口径

- 全题库：444 章、2340 个可玩任务。
- 教材单元与当前课程主题层：276 章、1690 个任务。
- 检查维度：完全相同题目、同单元相同题干、只换数字的模板近重复、跨年级复用、题型占比、单一题型集中度、热身/练习/挑战分布、理解/建模/熟练/诊断/应用/迁移证据顺序、教材单元编号连续性。
- “相同操作说明、不同语料/数据/答案”不直接判为重复题；“题干、选项、答案、语音、图示及交互数据均相同”才判为完全重复。

## 已发现并修复的核心单元问题

1. 四年级数学“条形统计图”原有 4 道题使用完全相同题干和同类读图操作。现已拆为读图含义、差量、合计、错图诊断、实际应用和数据结论六类任务。
2. 多个数学草稿单元虽然标记了“诊断、迁移”，实际仍是同一计算模板换数字。现统一重排为直接理解、配对建模、结果辨析、错解诊断、情境应用和迁移推理。
3. 9 个数学单元原来选择题为 4/7，超过一半。现已降至不超过 50%。
4. 二年级数学原来数字作答占 54%，现调整后各年级没有任何单一题型超过 55%。
5. 英语单元内两道听音题、两道阅读题原来共用相同题干。现按单元主题和任务序号区分，语料、语音和答案也保持独立。
6. 三年级英语与低年级启蒙内容存在 `This is my mother`、`This is my father`、`My name is Star` 等跨年级原句复用。三年级任务已改为家庭照片、爱好、家务能力和互助表达，形成难度进阶。
7. 二、四年级美术任务都写“铺 4 块花砖”，但画布总格数不同，题干信息不足且看起来重复。现明确写出 8 格或 12 格画布。
8. 自动生成的“线索连连看”原来所有章节共用同一句题干。现题干带入本章主题；操作说明仍保持一致，便于儿童形成稳定操作习惯。

## 核心单元修复后的自动校验结果

- 完全重复任务：0 组。
- 同一单元完全相同题干：0 组。
- 同一单元只换数字的同模板任务：最多 2 道，分别承担热身与应用，不允许连续复制 3 道以上。
- 选择题超过单元题量 50%：0 个单元。
- 某年级某学科单一题型超过 55%：0 组。
- 少于 3 种交互题型的课程单元：0 个。
- 语数英六类学习证据缺失或顺序错乱：0 个。
- 教材单元编号断号或上下册串号：0 个。

## 尚未修复：历史拓展题库跨年级重复

全题库仍有 **113 组完全相同任务**，每一组都至少涉及一个没有教材单元元数据的旧启蒙/拓展章节；部分自动图片任务是一份位于核心单元、一份位于旧章节。主要模式是同一学段的相邻年级共用同题，例如：

- 一、二年级英语旧气球听音题与问候组句题完全相同；
- 一、二年级语文旧反义词、排句和感谢表达完全相同；
- 三、四年级科学旧吸水、磁铁和实验步骤题完全相同；
- 五、六年级语文旧比喻、游记顺序和阅读证据题完全相同；
- 多个实践学科旧章节也采用“一二、三四、五六年级共用一个题组”的生成方式。

这些题没有进入本次“教材单元无重复”通过结论，但当前仍可能在完成教材单元后出现在学习路线尾部。因此，全题库目前不能认定为“各年级完全独立、无重复”。

## 严谨处理建议

优先建议把旧启蒙/拓展章节从教材主路线中归档到独立的“复习与拓展题库”，保留题目 ID 和旧存档兼容；之后再按年级重写，达到标准后重新进入主路线。直接删除会破坏既有完成记录，直接在题干后添加年级文字只会掩盖重复，均不建议。

## 自动门禁

新增 `npm run test:curriculum-audit`，发布前自动拒绝以下情况：

- 教材单元中出现完全重复任务；
- 同单元题干完全相同；
- 同一数字模板在单元内出现超过两次；
- 选择题超过单元任务的一半；
- 某年级某学科单一题型超过 55%；
- 单元少于三种题型；
- 语数英学习证据或难度阶段顺序错乱；
- 教材单元编号不连续。
