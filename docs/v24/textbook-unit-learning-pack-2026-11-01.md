# 小学教材单元学习包改造（2026-11-01）

## 本轮结论

课程导航已从“零散主题关卡”改为“册次 + 第几单元 + 单元目标 + 六类学习证据”的结构。只有已经在课程数据中标记为 `verified + textbook + unitNumber` 的内容才显示“第 X 单元”；总复习与尚未逐项核对的原创主题分别显示“总复习”和“课程主题”，避免把拓展题冒充教材原单元。

完成一个核心单元的六类证据为：理解、建模、熟练、诊断、应用、迁移。产品界面使用“核心练习完成”，不宣称已经替代课堂教学、教材阅读、实验活动或教师评价。

## 已落地的产品结构

1. 单元元数据增加 `unitNumber`、`unitType`、`objectives`，后台发布时校验已认证教材单元必须有单元号和至少三条目标。
2. 课程卡片、学习地图和作答页统一显示册次与单元号；地图底部直接展示当前单元的第一条学习目标。
3. 数学单元内部至少包含三种交互。原本只有数字作答或选择题的单元，补充了知识配对、结果辨析或推理步骤排序。
4. 英语按上、下册重新从 1 编号；六年级下册前四个教学单元与后续总复习分开，不再虚构 Unit 5、Unit 6。
5. 语文和其他学科仍标为课程主题，不显示精确教材单元号；必须完成逐册目录、课文和学习目标核对后才能升级为教材单元。

## 当前题型结构

课程内容共 2208 个可玩任务。核心课程中的选择题占比约为：数学 29%～32%、英语 33%、语文 29%、科学 22%～25%，其余实践类学科约 25%～29%。已接入的题型包括：

- 数字作答、装载建模、等量分组、铺格操作；
- 听音辨义、词卡组句、推理步骤排序；
- 线索配对、概念配对、图片分类、过程排序和拼图；
- 阅读情境选择与易错诊断。

考试组卷继续支持数字作答、排序和配对；非数学、非英语试卷设置选择题不超过一半的自动门禁。

## 仍未达到“学完即完整学完教材单元”的部分

1. 当前单元目标多数是三条核心目标，还没有逐条覆盖教材开篇大问题、每个小节/例题、课后练习、项目活动与复习栏目。
2. 英语每单元已有听、读、组句和理解任务，但词汇量、语音、书写、口语对话和 Project 仍只是核心样例，不等于教材全量内容。
3. 数学的六类证据形成了练习闭环，但竖式过程、尺规作图、一题多解、开放探究和综合实践仍需专门评分器。
4. 语文尚未逐册映射，缺少写字笔顺、朗读背诵、口语交际、习作与修改等关键学习证据。
5. 目前大部分题目仍是 `draft`，需要学科教师逐题审核和真实儿童试玩后，才能将“核心练习完成”升级为更强的掌握结论。

## 下一轮补齐顺序

1. 先做一个完整样板册：逐单元录入教材大问题、A/B/C 或小节目标、核心词句/例题、易错点和项目任务。
2. 每个单元建立“课前诊断—概念学习—分层练习—错因反馈—迁移任务—单元测评”的七段流程。
3. 增加主观作答：数学过程题、英语拼写/录音、语文朗读/写字/短表达，并明确人工或规则评分边界。
4. 建立教材版本选择，避免不同地区、不同起始年级或新旧版教材混在同一条路线中。

## 自动门禁

- 教材单元编号必须在同册内从 1 连续编号。
- 已认证教材单元必须有至少三条学习目标。
- 核心任务必须覆盖理解、建模、熟练、诊断、应用、迁移六类证据。
- 已认证数学单元至少有三种交互题型。
- 未认证主题不得显示“第 X 单元”或 `Unit X`。
- 六年级英语下册只允许四个教学单元，其余内容标为总复习。
