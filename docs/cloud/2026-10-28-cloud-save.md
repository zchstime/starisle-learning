## 范围与限制
- 已经存在于浏览器的进度无法从服务器凭空读取：用户需在原浏览器原账号刷新一次，待云存档成功后再换设备。
- localhost 与正式站点的认证数据目录仍彼此独立；不能假定两套环境新注册的同手机号天然具有同一 ID。正式站点各设备使用同一认证服务时正常共享账号。未来跨环境账号归并必须在验证手机号后做显式迁移，不按脱敏号码猜测匹配。
- 未完成题目当前拖拽/输入过程属于内存状态；保存的是已完成关卡、奖励和设置，不是逐帧现场。
- 分数/经验按已完成关卡派生，云存档不是反作弊成绩认证系统，不适用于兑换现金或正式考试判分。
- OSS 桶未用于这次历史备份；历史在 MySQL 内，尚未增加用户侧版本恢复界面。
- 本地新版本音乐设置按账号保存；线上旧游戏包仍有旧的设备级音乐设置实现，待游戏包正式更新后统一。
