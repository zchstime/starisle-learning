# 星屿学园 v0.2 架构与内容边界

## 用户路径

默认回到上次的学科/年级/章节。地图一键开始最近未完成任务；不要求儿童每次经过四层菜单。左上角“换学科/年级”打开课程库：学科 → 年级 → 章节卡。每章三站，完成一站直接下一站，第三站完成提供下一章入口。章节允许自由选学，不用刷前置课程才能复习。章节完成度与总星章独立展示。

游戏章节不是教科书单元编号。第二章切换花园岛，英语切换独立英语岛。未来增加学科只需新增课程与主题资源，再注册需要的玩法；原二年级拆捆、进位及独立试炼仍可从学习手册进入，并可返回新地图。

## 分层

- `adventure/Catalog.ts`：subject / grade / chapter / level 的稳定 ID，课程主题、对齐状态、场景、参数、提示、解释和语音。
- `adventure/Puzzle.ts`：纯 TypeScript 判定。运输用整数表示数位，金额用十分之一元整数避免浮点误差；等分、方格、单词顺序和听辨有独立规则。
- `adventure/Progress.ts`：版本 3 本机存档，跨学科独立关卡 ID、重复奖励去重、加载白名单、存储失败提示。
- `adventure/Adventure.ts`：Cocos 场景呈现、导航、玩法呈现、奖励、音频与资源加载。UI 统一 1440×810 等比缩放。
- `StarIsle.ts`：场景入口 + 保留 v0.1 经典模式。旧存档键保留，新版不把旧试炼成绩伪装成新任务完成。
- `resources/art`：原有岛与向导，新增花园岛、英语岛、透明飞船；均为原创生成素材。
- `resources/voice`：44 条本机合成英语 WAV。`resources/audio`：5 种短反馈音效。

当前 5 个玩法：运输配量、等组种植、方格分数/面积、口信排序、听音送气球。没有倒计时、生命损失或长篇前置教程。错题停留原场景，可撤回操作、重置或展开帮助。每次成功有解释和星章。只有完成任务与位置/音效偏好落盘，关卡中途摆放不保存。

## 人教对齐原则

数学按人教体系的核心知识主题组织，但不声称覆盖六个年级上下册全部单元。各年级先提供 4 个主题，每主题 3 个任务，共 72 个。仅做了核心主题映射，尚需逐册页码和版次教研复核。

英语按 PEP 三年级起点方向组织；一年级和二年级明确为启蒙，不标作 PEP 一二年级正式教材。三年级三个主题通过人教社官方页面核对；四至六年级是语言能力主题练习，尚未完成最新教材逐单元核对。英语共 18 章 54 关，其中启蒙 18 关。

## 扩展与限制

内容来自原创题目，没有复制教材插画或课文。当前同一主题的三关有固定参数，适合试玩和验证交互，尚不是随机题库或自适应学习。面积铺满、体积配量等任务可视化深度有限，后续可增加自主画矩形、堆立方体等更具体操作。星章表示完成，不表示独立迁移或长期掌握。

新增章节目前更新 Catalog，并同步课程库分页：当前每年级数学 4 章、英语 3 章，单页最多 4 张卡；不能无限追加而不做分页。新增学科需将 Subject、学科入口与手册统计扩展为注册表；当前两学科结构已分离，但尚非完整内容 CMS。生产版本应继续把 Adventure 的玩法分支拆成独立渲染器。

Web 版已构建；手机横屏等比适配。Android、iOS、小游戏尚未原生打包/签名/真机验收。正式小程序与小游戏是不同容器，需单独确认发行方式。没有账号、云同步、教师后台、正式考试或付费功能。
