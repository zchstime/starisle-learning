# v1.4 八科分年级探索路线

2026-10-27。本地开发版，未更新生产服务器。

## 本轮范围

科学、道德与法治、音乐、美术、体育与健康、劳动、信息科技、综合实践：每科覆盖1—6年级。每年级新增2个原创主题、6个任务，保留6个既有任务，共4个阶段、12站。八科共新增96个主题、288个任务；包含旧任务后共576个任务实例。全游戏目前444章节、1872任务实例。

每个新阶段由发现/应用选择、行动排序组成；音乐每个年级增加专门听辨，美术每个年级增加自由布局的定量拼贴。顺序卡可点回取出，选择题可重试；完成阶段获得勋章，本年级全部完成后进入下一年级，六年级结束后可探索其他学科。

所有学科统一浮岛地图，每科有自己的地点名称；扩宽中文步骤卡以容纳长文本。使用已有浮岛与星宝美术，本轮没有生成新的背景图或3D模型。

## 学段与对齐边界

参考教育部2022课程方案的学科框架，按低/中/高年级能力递进创作，不声称对齐某出版社每册每单元。上/下册字段仅表示游戏中的两组阶段，alignment=enrichment、verified=false。信息科技低年级任务为设备使用、数字习惯的启蒙体验，不声称所有学校均以独立学科形式在该年级开设。

官方参考：
- https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html
- https://www.moe.gov.cn/fbh/live/2022/54382/sfcl/202204/t20220421_620077.html

本轮是八科可玩基础系列的扩充，不是完整教材、考试或实践能力覆盖。道德与法治集中于共同生活与责任情境，并非完整法治知识体系。科学是观察、证据和实验规划练习，尚无完整物理模拟实验；体育不测动作质量或体能；劳动不代替真实操作；美术仅检查铺砖数量，不评判创作优劣；信息科技规划题不等于真实编程环境。部分旧关卡为共享学段样例。

## 核心文件

- assets/scripts/adventure/SubjectStories.ts：96个原创分年级主题，问题、选项、行动步骤。
- assets/scripts/adventure/OtherCurriculum.ts：组装任务与音乐/美术互动变体，稳定的mission ID。
- LearningRoute.ts / JourneyMap.ts：八科路线、专属地点。
- tools/make-other-audio.cjs：本机Tingting普通话合成。
- tools/make-mission-tones.py：六组原创听辨声音，固定频率/间隔/力度，不使用第三方歌曲。

原有任务ID、存档格式、已获勋章均保留。新增关卡会使尚未完成的新总进度增加，已获奖励不撤销。没有外网部署、短信发送或付费服务调用。

## 检查

逻辑测试覆盖全目录题目可解性、8科×6年级12站路线、顺序锁、3站勋章、重复奖励、升年级、六年级上限及存档。测试日志 qa/test-other.log。构建与试玩证据见下方补充。

## 下一步

逐科核对学校实际教材版次、扩展知识面和题目变式；优先将科学实验、信息科技指令执行做成可直接操控的场景，而不是继续单纯增加选择题。体育、劳动引入由成人陪同的线下实践记录后再讨论评价，避免游戏答题分数被误当作实际技能。

### 实际验收结果

- Cocos3.8.8 Web构建通过：qa/build-other.log；TypeScript检查通过。
- 281条普通话朗读文本、6组原创听辨声音，共287个唯一音频键，288处任务音频引用均有有效WAV；清单 voice-manifest.json。
- 浏览器真实点击八科代表任务均成功结算：科学1年级、道法2年级、音乐3年级、美术4年级、体育5年级、劳动/信息科技/综合实践6年级。
- 劳动6年级四步计划实际点卡排序通过；美术6年级点亮10块花砖后通过；六年级音乐听辨播放：AudioContext=running，lastPlayed=voice/tone_mission_g6，peak约0.400，无音频错误。
- 代表截图：qa/other-science-map.png、qa/other-science-play.png、qa/other-labor-plan.png、qa/other-art-tiles.png、qa/other-music-listen.png。
- 上述试玩使用独立内存存档，前后localStorage一致；已加载资源无HTTP>=400条目。批量逻辑测试覆盖所有任务，未声称逐题人工通玩全部288道新任务。
- 自动升年级实测：预置科学1年级11/12进度，实际完成最后一步排序，获得年级勋章；页面置前后倒计时结束进入科学2年级，保留5枚勋章。浏览器后台会暂停/放缓Cocos动画计时，不以后台墙钟时间判断失败。证据 qa/other-grade-medal.png、qa/other-auto-grade2.png。
