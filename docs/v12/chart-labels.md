# 数学图表语义标签修复 · 2026-10-27

线上部署试玩发现：二年级「整理小集市」题干说苹果和梨，辅助条形图却标成「星宝」「伙伴」，会干扰孩子理解数量关系。

本轮将 MathCurriculum 的双条形图帮助函数改为必须显式传入两个标签，逐项修正原有/送出、十/一、桥两端、红箱/蓝箱、水果类别、日期和观测先后。覆盖现有一、二、三、四、五年级相关任务生成器；保持任务 ID、题干、答案、教材映射与用户存档不变。内容仍是原创任务样例，教材对齐边界沿用 v11，不新增完整教材覆盖声明。

验证：npm test 全部通过（qa/test-chart-labels.log）；Cocos 构建通过（qa/build-chart-labels.log）。首次沙箱构建退出，随后正常权限构建成功。浏览器内存 SavePort 实玩二年级首站，显示「苹果 5」「梨 3」，点击8并完成任务后进入奖励页；localStorage 验收前后完全一致。截图 qa/chart-labels-play.png、qa/chart-labels-reward.png。
