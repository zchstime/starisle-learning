# 星屿学园：音乐与角色动作

## 交付
- 原创42.67秒循环主题《星屿漫步》：90 BPM、16小节，钟琴式主旋律、分解和弦、低音与柔和铺底。由 tools/compose-game-audio.cjs 确定性合成，不含第三方录音采样。
- jump / arrival / sparkle / reward 四组原创音效。分别接入角色跳跃、入关到站、拼花种植和通关奖励。
- 首次交互开启背景音乐，独立配乐开关与总声音开关；语音与听音题播放时自动降低配乐，结束恢复；切到后台停止配乐，返回后恢复。
- 星宝待机呼吸摇摆、点击跳跃、落地回弹、动态阴影，地图跳跃入关，环境光点，奖励粒子。

## 角色路线
当前是二维精灵加动画与阴影，属于2.5D表现，并非真正的3D模型。
若需要任意角度转身、稳定侧面、拿物品、绕建筑走动，建议单独为星宝制作低面数模型、UV贴图、骨骼蒙皮和动作（待机/行走/跳跃/挥手/拿物/庆祝）。先将角色放入现有2.5D岛屿验证风格，再决定是否把全场景三维化。
WorldMotion.ts 将角色外壳与视觉子节点分开，后续可替换角色视觉层；仍需增加3D相机、深度与遮挡、资源导入和跨端性能验证，不能直接替换图片就完成。
