# 提示切换保留角色姿态 · 2026-10-27

本轮完成一项交互修复，未添加课程、菜单或存档字段。

## 问题与修改

实际浏览器复现：进入六年级数学第一章第二站，拖动星宝转身，再点「教我一下」，角色摄影棚被重新创建，星宝转回正面。原因是提示按钮调用整个 `play()` 重绘；该路径也会调用停止朗读。

修改 `Adventure.ts`：提示按钮只更新提示 Label 和按钮文案，不重建关卡。现有提示开关状态继续由 `this.hint` 管理，因此之后装船等原有重绘仍能保持提示的展开状态。
