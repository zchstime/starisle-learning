# 小学数学 / 科学物理玩法试点

入口：Web 小岛地图左下角「游乐实验室 · 新玩法」，也可直接访问 `/arcade/index.html`。由 `web/arcade/launcher.js` 打开同源 iframe，关闭后返回仍在运行的原 Cocos 地图，不替换现有 curriculum。`tools/prepare-web.cjs` 负责复制资源和注入入口。无需为了试点重新编译 Cocos。

## 已落地

- 数字弹弓：凑 8、12、20 三关。选择能量球，拖拽弹射或使用角度/力度和发射按钮。真实重力、碰撞、积木和能量入口。未命中不扣能量，溢出清空能量后可重试，没有答错惩罚。数字组合是玩法目标，不额外弹出选择题。
- 平衡实验：等重等距、轻重不同而力矩相等、不同组合三个关卡。用砝码重量和离支点距离控制真实复合刚体；必须满足规则且水平稳定 1.4 秒才成功。右半边桥面支持点击选择距离，按钮支持键盘操作。
- Kenney 3D 角色、云、草、地形、金币；Matter.js 0.20 / Three r170 本地资源。
- 暂停 / 后台自动暂停 / 首次操作解锁音效 / 可静音 / 本机星章 / 重玩 / 模型降级提示 / WebGL 不可用提示。

## 边界

这是 Web/H5 的九关试点，未覆盖全题库，未实现原生或小程序适配。不是现成塔防游戏完整移植；复用的是官方弹弓实现模式、物理引擎与开放模型，课程与界面适配由项目实现。塔防候选与后续方向见 web/arcade/SOURCES.md。

星章为本机练习记录，从主游戏进入时按 `starisleAccount.id` 隔离。直接访问使用访客记录。不会写入原课程 `done` 或云端积分，不将开放试验等同于课程测评。完整替换课程应增加题目与玩法的映射、难度分层与服务端验证。

## 验证

`node tools/test-arcade.cjs`：数值组合、溢出恢复、各关可达性、Matter 实际弹道进入感应区域、杠杆不同力臂的物理平衡、静态素材引用和许可证完整性。

浏览器：原六关完成，按钮发射；另测拖拽、超量恢复、暂停、移动尺寸、主游戏入口返回。浏览器截图保存在 docs/arcade 中。
