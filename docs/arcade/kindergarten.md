# 幼儿园小岛

入口：主游戏地图的「幼儿园小岛」或 /arcade/kindergarten/index.html。

独立试点，复用星屿浮岛、正式星宝角色、现有声音设置；不改变其他年级课程。

孩子界面不显示文字题目或数字答案。喂兔子按苹果图样匹配数量（2、3、4），水果按相同图案分类，积木按样例自下而上搭建。每项 3 关。首次进入和帮助按钮提供语音与非计分的小手示范；拖拽或点玩具再点目的地均可。错误返回原位，无倒计时和扣分。进度仅存本机，家长说明独立收起。

语音为本项目现有服务生成的固定中文台词，提供静音和重听。设备禁止自动播放时仍可看演示。图标有屏幕阅读器标签。

验证：test-kindergarten.cjs 覆盖 9 关、错放、重复、超量、积木顺序和全部语音文件；既有 arcade 两套测试通过。浏览器验证点选、错误保留、暂停后完成、语音播放状态、示范和 390px 竖屏无横向溢出。浏览器实际拖拽已成功放置，重置后示范不计分。未开展真实幼儿可用性测试。
