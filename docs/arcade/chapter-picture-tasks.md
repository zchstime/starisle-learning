- 306 个章节增加「线索连连看」：从该章两至三个不同答案的现有任务组合成配对练习；不是 306 份新的知识点。重复答案、阅读篇章、听音判断不自动转换，避免模糊配对。
- 六个年级各增加 3 个数学、2 个科学操作任务，共 30 个。依主题追加到原章节，走相同进度、积分、经验及勋章流程。

- 高年级包含小数分装、1∶2 分配、分数/小数/百分数比较、光照控制实验、物质变化与证据顺序。科学过程桥是概念排序，不是电路或化学仿真。

## 体验

`/arcade/chapters/index.html` 可切换 1—6 年级与数学/科学，独立体验不计课程积分。游乐实验室页提供入口。正式章节进入 picture 题型时由 Cocos 打开全屏任务，正确后回到原奖励页。

`PictureActivities.ts` 为单一内容与判定源；`tools/prepare-picture.cjs` 生成浏览器和服务器模块。`Catalog` 与兼容内容加载器补充任务；管理员已有发布版本不会被改写。刷新客户端后，旧发布内容也可得到兼容扩充。seed 已同步供新内容库使用。

iframe 只能提交位置数组；宿主检查来源、当前题目和完整答案后调用原奖励逻辑。对相同果子、方砖按数量判定，不要求固定卡片身份。退出恢复主游戏声音。新增 ID 保留旧存档和已获得的勋章；新增任务计入后续章节/年级完成条件。

## 美术与声音

复用正式星宝模型、浮岛背景、幼儿园玩具 SVG、Three.js 和 Kenney 音效。新增数学图形为本项目 SVG；部分科学物品使用系统彩色字形，外观可能随设备变化。36 段本地中文音频复用项目配置的星宝音色（台词和散列在 chapters/voice-lines.json 与 assets/voice/manifest.json）。无运行时语音 API 调用。小手支持静音时的操作示范。
