# v1.3 语文星岛系列（本地）

日期：2026-10-27。入口：http://127.0.0.1:7456/?v=1.3-chinese 。本轮未发布到 xy.laiyiju.com。

## 内容范围

小学1—6年级，每年级新增6个主题阶段，每阶段6站：2个字词/句法任务、1个拼句、1个事件或步骤排序、2个短文阅读任务。合计216个新增任务、36篇原创短文；加上保留的每年级6个旧任务，每年级42站、全系列252个任务实例。旧任务ID与存档格式保持不变，旧任务可能包含共享样例，不等同于252道独立原创题。

- 一年级：拼音识字、形近字与量词、礼貌表达、反义词、故事顺序、简短阅读。
- 二年级：词句、声音描写、留言、故事理解、观察、复述。
- 三年级：词句修整、通知、故事线索、段落、观察日记。
- 四年级：提问、人物行为、游记顺序、说明、概括、表达。
- 五年级：人物细节、说明方法、故事复述、信息提取、景物变化、建议表达。
- 六年级：中心意思、人物线索、按目的阅读、观点与依据、原创文言小故事、编辑整理。

依据统编语文能力方向和《义务教育课程方案和课程标准（2022年版）》设计原创游戏任务。官方依据：https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html 。未逐课核对2026年各册实际使用版本；配置中的上/下册是游戏进阶分组，不是已验证的教材单元顺序。所有新增章节 alignment=theme、verified=false。暂不覆盖完整写字、作文批改、朗读评分及全册考试题型。

## 游戏与音频

沿用浮岛路线、逐站解锁、六站阶段勋章、年级远航勋章与通关后自动升年级。语文岛命名为字词小屋、故事灯塔、阅读之树、表达之门。拼句使用较宽文字卡和逐块点亮的桥板；阅读使用独立短文卡，答案与选择状态分行，修复试玩发现的重叠。

新增59个普通话合成朗读音频，覆盖95处任务引用；同一篇阅读短文复用音频。macOS Tingting离线合成，生成脚本 tools/make-chinese-audio.cjs；拼音字母题未自动朗读，避免把拼音当英文读。清单见 voice-manifest.json 与 chinese-manifest.json。
