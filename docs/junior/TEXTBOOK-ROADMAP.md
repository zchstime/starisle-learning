# 人教版七年级上册数学：教材对齐开发计划

更新：2026-11-01。用户已确认优先人教版七年级上册数学。保持每 30 分钟一轮增量开发；一轮不等于一个完整阶段，以验收条件推进。

## 基线与版本

目标为六三学制、人教版七年级上册数学，优先核对 2024 修订教材。用户尚未指定印次，不宣称已完成逐页同步。现有 17 个单元属于原创课程主题样例，不能仅改标签就称为教材同步。其他学科及八、九年级保留已有功能，新增内容优先投入本计划。

教材记录至少包含 publisher、edition、grade、semester、chapter、section、sourceURL、verifiedAt、verificationStatus；页码仅在核对实际版本后填写。来源核实状态与教学审核状态分别记录。题目、场景和插画原创，不整本复制课本内容。

## 阶段安排与验收

|阶段|开发范围|游戏化学习形式|完成条件|
|---|---|---|---|
|0 当前优先|核验新版目录、建立教材映射与缺口清单；界面区分教材路线和原有样例|章节航线、前置知识提示|逐节有可追溯来源；没有核实的条目明确待核实；旧存档可继续|
|1|有理数概念：正负数、数轴、相反数、绝对值、大小比较|温度站、数轴定位、镜像点、距离测量；要求操作并解释|覆盖概念和典型误区；正负零、分数等边界测试；不能只做整数位移|
|2|有理数运算：加减乘除、乘方与混合运算等，按核实目录细化|航行指令、能量账本、运算步骤修复、路线比较|规则与情境匹配；正确过程可核验；运算顺序、负号与括号有专项反馈|
|3|代数式与整式的加减，按新版章节分别组织|物资公式建模、代数拼块、同类项归仓、去括号修复|变量意义明确；支持不同合法表达；合并与去括号不能混同|
|4|一元一次方程：等式性质、求解与实际问题|天平操作、预算任务、分步推理、代回验证|从情境列式到检验形成闭环；不止检查最终答案；保留现有解题过程存档|
|5|几何图形初步：立体与平面、直线射线线段、角等|模型观察、线段搭建、角度仪、几何语言解释|模型与数值一致；图形操作可用键盘；不把近似视觉判断当精确证明|
|6|全册综合与复习|跨岛任务、错因回访、间隔复习、作品记录|覆盖清单可追踪；客观核验与待复核作品分开；完成工程测试后仍标明教学审核状态|

阶段 1 起，每个知识点至少包括探索操作、解释理由、变式应用、延后复习；先做一个完整知识点，再扩展同章，不用大量重复题充当覆盖率。美术继续沿用已完成的浮岛和星宝风格；音频按真实教学需要制作，默认不自动播放。

## 现有内容的迁移判断

- `m7-numberline`：保留 ID 和历史记录。现有任务主要练习整数加减与路程，不能据此声称覆盖“有理数”全章；新增概念任务使用新 ID。逐任务核验后再建立跨章关联。
- `m7-equation`：保留 ID 与分步等价核验。当前缺少从情境自主列方程、等式性质的可操作探索，需要补齐后才能称作章节路线。
- 其他单元仍显示原创主题样例，不能因数学对齐而批量改变教材标记。
- 每轮先检查本文件、最新代码和迭代日志；新增任务改变答案或评价规则时使用新 ID 或显式版本迁移，避免旧完成记录套用新题。
