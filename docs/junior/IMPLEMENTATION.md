# 初中研究站实现记录

2026-11-01。本地样板版；未部署生产。

## 当前可用范围

- 独立 Web/H5 入口 `/junior`，主学段选择器可进入。该模块不是 Cocos 场景；小学 Cocos 学习内容与存档格式不变。
- 14 个课程分类，17 个原创单元，68 个任务，15 种交互。七年级 13 单元、八年级 2 单元、九年级 2 单元。课程和任务清单由 `tools/audit-junior.mjs` 写入同目录 `development.json`。
- 各单元按探索、解释、应用、复习组织，可自由切换；界面有年级、学科和学习方式筛选。当前按六三学制编排主题，未完成地区教材版次或五四学制映射，不声明完整同步教材。
- 数轴、分步方程、原文证据、写作修订、英语逐轮交流、植物对照实验、函数图像、理想电路、化学配平、气候数据、探测车程序、八拍乐句、像素画布、实践项目记录均可操作。

## 判定与证据边界

- `engine.mjs` 是浏览器与服务端共用的规则引擎。方程使用受限线性表达式解析器，不执行输入代码；检查逐行等价和至少一个中间步骤。机器人只执行 F/L/R，限制 80 条。
- 数学、配平、数据、算法等返回 `verified`，只表示当前任务规则通过。英语检查有限的信息表达模式，不评价发音或整体口语能力，也可能漏识别合法表达。
- 阅读、写作、修订、艺术和实践等返回 `submitted`，只表示格式要求满足和作品归档，保留“内容待复核”。AI 学习伙伴可讨论当前问题，但不能修改正式结果、授予掌握等级或代替教师评价。
- 实验数据是明确标注的简化模型；历史工场材料是明确标注的教学模拟资料。线下实践记录是学生自述，不当成动作、劳动成果或健康状态的自动证明。
- 每个任务保存最近五次提交、相应作品版本和提示使用标记。重新编辑时明确区分当前草稿与上次提交结果；完成标记不称为掌握率。

## 保存与服务

- 游客记录：`starisle.junior.v1.guest`，只在本机。账号记录按用户 ID 使用独立键，游客数据不自动导入账号。
- 输入即时存本机；“保存草稿”与提交按钮保存至账号。`GET /api/junior/state`、`PUT /api/junior/tasks/:id` 使用现有登录、同源检查、账号 ID 校验和任务级 revision CAS。
- 服务端重新校验草稿并计算提交结果，不信任客户端分数。过期 revision 返回冲突，不静默覆盖。冲突选择前可下载双方版本备份；不同任务互不覆盖。
- SQLite 在 `JUNIOR_DATA_DIR`（默认 `local/junior`）中；配置 MySQL 后使用独立 `junior_tasks` 表。存储延迟初始化，浏览公开课程不创建表。SQLite 路径已测试；生产 MySQL 连接和迁移尚未实测。
- 存储故障保留本机草稿并显示错误，不声称已同步。损坏的本机记录先备份；备份失败时阻止覆盖并提示导出。
- 页面关闭、切换任务、后台隐藏时停止音频。声音默认关闭，点击示范或试听会启用声音；随时可以静音。

## 美术与音频

- `web/junior/assets/research-station.png`：内置 image_gen 生成的独立研究站主视觉；完整提示词和声音规则见 `art-direction.json`。
- 课程卡片沿用统一色彩和排印；函数、实验、电路、原子计数等使用数据驱动 SVG/HTML，保证操作状态与图形一致。
- 9 条英语角色示范 WAV 使用本机 Samantha 系统合成语音生成，文本与来源在 `web/junior/assets/audio-manifest.json`。重建：`npm run build:junior-audio`，需要 macOS 对应语音。
- 反馈音和创作台音高使用 Web Audio 本地合成，不需要额外付费接口或运行时外链资源。

## 验证与运行

- `npm run test:junior`：解析、任务判定边界、账号隔离、来源检查、CAS 并发、SQLite 重开，以及 DOM 交互、草稿恢复、作品版本、文字注入防护。
- `node tools/audit-junior.mjs`：课程结构、学科覆盖、音频 RIFF/WAVE 格式及示范文本一致性。
- 本轮 `npm test`、`npm run test:companion` 通过；首次接入执行 `node tools/prepare-web.cjs` 更新现有 Web 壳层。初中源文件由 Node 路由直接服务，不需要重编译小学 Cocos 场景。
- 浏览器截图保存在 `qa/junior/`。本机隔离试玩服务为 `http://127.0.0.1:7488/junior`；它使用临时演示账号库，不发送短信，也不读取生产学习数据。
