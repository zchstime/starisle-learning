# 游戏加载画面

将纯色文字等待页替换为浮岛背景、星宝悬浮、星光闪动与金色进度条。复用已有原创 island/guide 美术，避免引入额外风格。HTML 加载壳在 Cocos 引擎初始化前显示，登录页层级在其上；Cocos 地图可交互后淡出。

进度按实际资源准备阶段推进：地图资源完成计数（4—75%）、星宝模型准备（78%）、音效准备（90%）、地图就绪（100%）。这是准备阶段进度，不是下载字节百分比；不会用定时器虚构加载完成。超过 45 秒提供重连按钮，保留已有存档。提供 prefers-reduced-motion、窄高屏适配及进度条 aria 属性。

实现：web/auth/loading.js、loading.css；Adventure.start 发出资源阶段回调和 world-ready；prepare-web 构建后复制素材并注入加载壳。新增账号音乐偏好使用 AccountStorage。

验证：Cocos TypeScript、npm test、真实 Cocos Web 构建通过（qa/cloud-loading-final-build.log）。浏览器实际登录、加载自动淡出、地图进入答题通过；qa/game-loading-arrival.png、qa/game-loading-progress.png。断网存档与恢复参见 docs/cloud/2026-10-28-cloud-save.md。

仅本地构建已包含加载新画面，未在自动迭代中发布到外网。原生端仍保留 Cocos 内部简化等待文字，后续需要专门的原生加载组件。
