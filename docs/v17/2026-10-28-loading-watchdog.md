# 加载停滞提示修复

原加载壳在打开 45 秒后固定显示重连，即使资源持续加载。现改为每次进度实际增加后重新计时，连续 45 秒没有进展才显示；恢复进展自动收起按钮，重复进度不会掩盖停滞。完成时清除计时器，忽略非有限进度值。

验证：npm test 全部通过（qa/test-loading-watchdog.log）；真实 Cocos Web 构建成功（qa/build-loading-watchdog.log）。首次沙箱构建进程退出 134，授权本机构建后成功。

浏览器会话 37 使用构建后的 loading.js/css 及真实图片进行独立加载壳验收，以可控时钟模拟长等待：40 秒推进到 30%，再过 10 秒无重连；无进展累计 45 秒出现重连；相同进度保留提示；推进到 60%收起提示；NaN 被忽略；world-ready 后 350ms 移除加载层。截图 qa/loading-watchdog-recovered.png 已检查。未修改用户账号或存档，任务会话已关闭。
