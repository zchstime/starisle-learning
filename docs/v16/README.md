# v1.6 · 星怪挑战、积分成长、符石投送

2026-10-27，本地版本，未部署。

## 玩法
- 普通无阅读材料、无颜色提示、非音高听辨的 choice 题改为符石投送：拖答案进入星光阵，也可先点符石再点阵心。拖出目标区自动归位，不提交答案；放入后仍由用户点击发射确认。
- 其他题保留数字输入、装船组合、分组种植、格子拼图、卡片排序、听音选择及阅读选择，避免将阅读材料挤进拖拽界面。
- 所有题型共用章节星怪战斗：护盾数量等于章节未完成的任务数，每个新答案破一层护盾。星光投射、粒子命中、音效后进入奖励；复习不再次削减已完成任务护盾。
- 可爱的程序绘制云朵星怪使用现有 Cocos Graphics 动画，非新增3D模型。打怪效果是学习反馈，不改变题目判分。

## 积分与迁移
- 每个唯一完成任务100积分、30经验；每180经验升一级，初始Lv.1。
- 积分/经验从已校验的done任务ID推导，无额外可不同步的计分字段；旧存档完成题目自动计入。存档版本仍为3。
- 答错不扣分；提示不扣分；反复完成同题不刷分。升级是展示性成长，不提供跳关或答题数值优势。
- 首页、侧栏战斗状态、奖励页、勋章手册展示积分/等级。仅当前本机账号存档范围，不是云端可信排行榜；尚未增加商城或兑换。
