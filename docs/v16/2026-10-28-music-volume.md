# 2026-10-28 02:06 配乐音量档位

在声音面板加入“轻柔 / 适中 / 明亮”三个配乐音量档位（0.2 / 0.4 / 0.65）。默认保持此前音量。设置单独保存在 starisle.musicVolume，不改变账号或进度格式；无效值回退默认。Web Audio 平滑调节增益，原生 AudioSource 同步音量，朗读时仍按比例压低配乐。原有全部静音、配乐开关保留。
