# AI学情评测与适龄练习 · 第一版（2026-10-28）

## 产品方向与实现
保留旧口算规则路径，新增 assessment 模式，入口仍在首页“拍照识题 · AI训练”。确认小学1—6年级与学科，不从图片猜年龄。支持全部现有小学学科选项，但本轮实际视觉与教学验收仅覆盖二年级数学；不是全学科质量认证。

流程：私有OSS图片 → 通用转录（题干/学生作答/质量）→ 用户核对 → 有证据的初步学情观察 → 适龄6道四选一原创任务 → 第二次AI独立解题审校 → 游戏练习/解析/每题10星光 → 本轮反馈 → 下一轮巩固或迁移。
报告提供原题编号、证据展开、今天/明天/三天后建议，每次5—15分钟。今天明确连接下方六站；后续天数为建议安排，不是已生成整套每日课程或已设置提醒。
完成后“按本轮表现安排下一轮”复用错误题，全部正确则用全体题作迁移输入，创建核对记录，再生成新任务。同一轮重复点击返回相同后继记录；继承账号、年级和学科，分轮积分。新评测会参考同账号同年级学科最近5个已完成记录（计分反馈和知识点，不传其他账号资料）。

## 评测约束
模糊、遮挡、未作答、低识别置信度不参与学情推断，单独列出待补充资料。OCR置信度只用于服务端筛选，不传给评测模型，避免被误解成学生信心。无有效已答题时不生成诊断。用户可以修正文案，但不能直接覆盖服务端原始置信度与遮挡标记。
只称本次观察，不设智力/性格/学习障碍标签，不宣称替代教师或全面掌握。模型对题目/报告仍可能错误；第二次调用是同模型独立审校，不等于独立权威认证。开放写作、艺术表现、体育动作不据一张图片自动量化能力。
当前练习以四选一运行，按服务器保存的AI审校答案判分，客户端不收到未答题答案/解析；不是所有学科的确定性证明器。旧算式路径保留程序独立验算。
