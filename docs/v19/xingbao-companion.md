# 星宝语音陪伴 v1 · 2026-10-28

## 体验与连接方式

在现有游戏上增加可收起的星宝对话气泡，不增加必经页面。第一次进入欢迎，有进度则说“接着探索”；开始任务、答错、过关和升级各有短句。点击星宝或左下角“星宝陪你”可主动呼唤。

- “给我提示”：在答题页打开该题原有提示；地图上说明怎样继续探索。保留当前答案和尝试次数。
- “我自己想想”与“休息一下”：回应后暂停主动提醒十分钟，用户仍可主动呼唤。
- 停留60秒才提醒，同一个页面/任务只提醒一次，跨任务至少间隔180秒。普通自动台词至少间隔20秒，不逐次播报所有操作。
- 探索20分钟后，只在地图上轻声建议休息一次，不打断考试。
- 进入考试、目录、登录弹窗或页面隐藏时停止陪伴播报。听题优先。关闭全部声音立即关闭陪伴；陪伴也可单独关闭及调整音量。
- 文字始终可读。浏览器首次需要用户手势才能发声时，可点“听星宝说”；不假装已经播放。

更长期的连接方向：以学习事件驱动短回应 → 根据经过核验的知识点给个性化提示 → 用户主动发起的文字/语音问答。不要用无休止闲聊、催促或连续弹窗替代学习，也不把AI判断包装成老师的绝对结论。

## 火山能力及资源

使用官方 **豆包语音合成2.0**，音色库“可爱女生2.0”：`ICL_uranus_zh_female_keainvsheng_tob`。14条原创短句已通过真实API生成，软萌、清晰、温柔的角色演绎指令；欢迎语约6.77秒。

接口参考：https://docs.volcengine.com/docs/doubao-voice/unidirectional-streaming-text-to-speech-http?lang=zh

服务端适配器：`server/providers/volc-speech.cjs`，HTTP分块JSON/Base64，60秒超时，限制输入/响应大小，拒绝错误码及空音频。专用凭据保存于被Git忽略的 `local/cloud/speech.json`，权限600，未进入前端。

开发者运行 `node tools/generate-companion-voice.cjs` 生成配音，音频和台词指纹在 `assets/resources/voice/companion/`。相同台词不会重复生成。**没有开放按用户输入随意合成的公网接口**，运行时播放静态资源，不按点击调用收费API。原有SoundBank负责播放、背景音乐压低及总静音。声音设置按当前账号保存在本机，暂未纳入云设置同步。

说话时气泡有音波标识、星星轻摇，地图3D星宝轻微点头。当前是说话姿态反馈，并非口型/音素驱动；模型没有在这次改动中增加嘴部骨骼。当前对话壳为Web/H5 DOM实现，原生和小程序还需要等价Cocos UI适配。未启用麦克风或自由聊天，也不发送学生资料到语音合成服务。

## 验收

- `node tools/test-companion.cjs`：60秒边界、同关只提醒一次、跨关冷却、十分钟安静、考试/忙碌屏蔽、台词音频清单一致、分块拼接和失败处理通过。
- TypeScript `tsc --noEmit`、`npm test` 既有全套逻辑检查通过。
- `npm run build:web` Cocos 3.8.8 构建成功，日志 `qa/build-companion.log`，未部署外网。
- 隔离预览7482，游客存档与真实用户分离：欢迎播放、呼唤、答错鼓励、提示按钮保留尝试次数、填写8过关获得100积分通过。
- WebAudio实际状态running，`voice/companion/wrong`播放，非零峰值0.3966；播报时音乐增益下降。
- 静音后手动重播仍无声；总静音后人声和音乐均停止；进入考试陪伴隐藏、人声停止。
- 浏览器中将隔离测试策略的活动时间调早61秒，验证真实提醒渲染及once标志（此项加速验收，不声称实等一分钟）。
- 证据：`qa/companion-welcome.png`、`qa/companion-play.png`、`qa/companion-final.png`、`qa/companion-regression.log`，qa不进入仓库。
