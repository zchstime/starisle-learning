# 作业照片混合运算识别修复 · 2026-10-28

原因：旧提示词排除混合运算，验证器与前端核对表单仅支持 a op b，最大20题。用户图二的21道口算均为两步混合运算，因此旧版本无法接收，且所有错误统一显示清晰度/范围提示。

修复：
- 支持两个或三个整数的单步/两步算式，最多40题；三数两步按先乘除后加减、同级左结合独立验算，无 eval。各步限制0..100整数，乘除按表内范围，无括号和余数。
- 保留旧a/b/op记录兼容，完整expression可在核对页编辑，服务端重新校验。
- 模型按原题提取，排除应用题解答过程；部分不支持项不拖垮全部有效题，显示识别数量和未纳入数量。
- AI生成支持完整混合算式，独立验证答案/重复/目标类型；基础降级生成也支持混合运算。
- 区分无支持题、模型格式异常、超时及一般服务失败。日志只输出固定验证错误，不打印原图、凭据或学生信息。
