# 数学渐进挑战 · 2026-10-27

本轮为数学一年级到六年级各加入一个独立的第六章，共 18 个任务。每章三站：热身、运用、挑战。保留既有 486 个任务及 ID，总计 168 章、504 个可玩实例。旧任务不重置，旧勋章不收回；当前年级完成条件包含新增任务。

## 难度与互动

- 一年级：从逐个对应、一步减法，到先减后加；不限制能量块数。
- 二年级：从乘法、平均分，到数量组合；最后一站最多用 6 块装出 24。
- 三年级：乘除法到两步运输计算，最后一站用不超过 6 块装出 28。
- 四年级：多位数运算到先求总数再扣除已送数量，最多 5 块装出 180。
- 五年级：小数总价、单价到购物优惠，最多 4 块付出 4 元。
- 六年级：百分数正向应用、分数逆向求总数到剩余量问题，最多 6 块装出 60。

任务属于小学数学核心主题的原创应用与数量组合练习，不代表具体人教版次逐课对齐或完整教材。二年级起的块数约束是游戏中的组合条件，不以超纲计算或时间压力提高难度。关卡清单、提示与目标见 challenges.json。

## 帮助与反馈

热身关开始即显示第一步思路；其他两站默认独立尝试。可点击「教我一下 → 再给点提示 → 收起提示」逐步获得帮助。连续两次提交未通过后主动展示提示，后续失败可加深提示，已经展开的较深提示不会被退回。

装船判定同时检查目标数量与块数上限。数量不足、数量过多、数量正确但块数过多分别反馈；不会因为数量已正确就忽略组合要求。玩家可继续取回和添加，完成后沿用原有星章、勋章及年级衔接。没有新增存档字段。提示更新仍只修改文字，保留角色状态和当前操作。
