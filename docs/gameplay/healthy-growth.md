# 星屿学园 · 观星花园设计

2026-11-01。目标：孩子学一点、亲手改变星球、满足地结束；下一次回来继续自己的建设。当前代码覆盖 Cocos 主线与趣味练习，不含独立网页小游戏，未发布。

## 一次完整体验

1. 进入：星宝说“今天一起照顾观星花园吧，做一个小任务就很好”。不展示欠下的任务、损失或补签。
2. 学习：选择一个适合当前学段的任务或复习任务。答错保留进度；趣味练习连续两次出错展示具体解释。
3. 完成：先告诉孩子“今天已经照顾过星球了，可以安心收工”，再展示学习成果。提供“今天先到这里”和“看看我的星球”，不自动开始下一题。
4. 建设：有树苗时任选新芽树、月光树、暖阳树，再点击空地。点已有树木后，可点另一块地移动或交换，也可换外观。所有外观平等，不额外收积分。
5. 离开：成长永久保留。建设没有倒计时，树苗可以留到以后种。

## 已实现：孩子拥有决定权

花园有八个可点击地块，展示树木图形。三种外观都可直接选择；位置和外观保存到账号存档。超过八棵的树苗保留在苗圃，界面显示库存；不要求全部摆完。

每三个首次完成的主线或趣味任务获得一棵树苗，复习不重复发积分和树苗。旧存档已有树木自动安排到地块，孩子可重新布置；新获得的树苗进入苗圃，由孩子决定种在哪里。尚未获得树苗时，提示它会随学习慢慢长出，不要求今天攒齐。

故事按已种植数量推进，属于花园布置进展，不是掌握度：

| 状态 | 星宝回应 |
| --- | --- |
| 尚未种植 | 一起种一座观星花园吧，你来决定它的样子。 |
| 种植一至两棵 | 第一片树荫有了！星宝在这里发现了一条观星小路。 |
| 种植三至五棵 | 树荫小路连起来了！为观星台布置你喜欢的树吧。 |
| 种植六棵以上 | 观星花园建好了！星宝邀请你坐下来看看星空。 |

本版故事以文字回应呈现；观星台建筑、道路与星宝专属动画尚未制作。

## 已实现：一次照顾就足够

完成一个任务或一次复习，即完成当天一次照顾。不同任务各产生一份晨露，每天最多三份，这是奖励上限，不是必须填满的任务条。重复完成同一任务不重复计入。

累计有学习的七个日期获得一朵纪念花，不要求连续。纯登录不奖励，离开不会枯萎或清零。示例：今天只复习一个旧任务，也能收到完整的完成反馈和一份晨露，但不会重复领取首次通关积分。

## 后续设计：从通关到真的学会

先补题池标签，再开放隔日验证；不直接把提高难度交给无约束生成。

| 学习状态 | 进入条件 | 下一步 |
| --- | --- | --- |
| 正在探索 | 初次接触或尚未独立完成 | 普通练习，允许提示 |
| 有帮助完成 | 使用提示或看过答案后完成 | 收到完整奖励，但不标“已掌握” |
| 独立完成 | 首次尝试、未看提示完成 | 下次学习时提供一道同知识点变式题 |
| 隔日验证通过 | 不同日期独立完成对应变式题 | 显示“已验证一次”，仍允许以后复习 |

每次最多推荐一道待复习题，可跳过，不产生欠账。没有经过核对的变式题时不展示验证入口，也不拿原题重复作答替代迁移验证。出错后回到讲解，记录本次需要帮助；永久收藏不回收。

必要数据：知识点 ID、题目与版本、变式关联、首次作答结果、提示使用、完成日期。历史通关记录统一标记“完成方式未记录”，不能追认独立掌握。

## 后续设计：家长看到具体证据

家长页按“今天学了什么 → 哪些独立完成 → 哪些需要帮助 → 下次可复习什么”呈现。示例格式：“完成两项词义练习，其中一项使用过提示；建议下次用另一种情境复习该词义。”仅在有对应真实记录时输出。

显示实际活跃学习时长，排除后台、暂停和花园布置时间；缺少计时记录时显示“暂未记录”，不估算。累计学习天数与连续天数分开，默认突出累计；不比较班级排名。报告入口需遵循既有家长身份机制。

当前未实现上述作答证据、隔日变式验证和家长报告，不将花园成长解释为知识掌握。

## 存档、冲突与失败

care 保存本地日期与任务 ID，云端并集去重；多个离线设备同日记录合并后显示仍最多三份晨露，只累计一个照顾日。设备日期不作为可信考勤。

gardenLayout 保存八个地块的外观与更新时间。云端选择时间较新的完整布局；同时间采用固定顺序解决，避免两个设备来回覆盖。离线同时编辑时可能保留其中一份布局，不会丢失已赚取的树苗，孩子可以重新布置。保存失败明确提示，不声称已保存。

## 验证与验收范围

规则测试覆盖：树苗数量、库存不足、外观更换、空地移动、占地交换、越界、积分不变、重载、旧存档迁移、云端新旧与同时间冲突。既有主线、趣味练习和云存档测试通过。

当前默认 TypeScript 检查受到另一个现有文件 PictureActivities.ts 中 Array.at 与 ES2020 库配置不一致的影响；以 ES2022 库运行类型检查通过，本次未更改该文件或项目库配置。尚未完成 Cocos 构建后的视觉和真人交互验收。

上线验收重点是孩子能否自主布置、完成一次后安心停止、隔日独立作答是否改善，以及家长能否看懂证据。随机盲盒、班级社交及额外货币暂不加入。
