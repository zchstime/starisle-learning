# v1.1 统一远征地图与英语主题任务

## 设计
数学与英语共用 LearningRoute + JourneyMap。地图保留每页12站，使用两段路径、圆形路标、一个上下文目标面板。删除每站重复说明卡和第二层大横幅；仅当前站显示“下一站”，阶段终点显示奖励。统一背景、按钮与任务面板降低视觉噪声。既有角色、账号及进度存储格式保持不变。

## 英语范围
每年级新增12个主题阶段，每阶段6站（2听音、2拼句、2阅读理解），共新增432个原创任务；加上原有72个任务，英语总计504站，每年级84站。每阶段完成获得一次勋章，全年级全部任务完成后6秒倒计时自动进入下一年级，也可立即进入或留在本年级；六年级封顶。
一年级、二年级是启蒙内容，非人教三年级起点教材。一至六年级目前不是完整教材或考试覆盖，也未包含语音评分、开放写作。
三至六年级按照人教社当前电子教材目录主题选编；主题核对不等于逐课词汇、语法和难度完整匹配。题目为原创，不复制教材原题。五年级下册采用1212001502255新版主题（规则、社区、四季、家乡、旅行、旅行计划）；旧版仍在官网并列，未作为新版目录。六年级下册官方当前链接1212001602145为四单元，另增加两段主题巩固。
