# v1.0 数学教材主题与连续远征地图

2026-10-27。本轮在现有 Cocos 3.8.8 工程升级数学，不修改用户账号或真实存档。

## 可玩的变化

- 数学由每年级18个任务增至90个：新增12个主题阶段×6站=72站，加原有18站作为巩固路线。六个年级共540个数学任务；全学科合计936个任务、240章。
- 首页改为连续蛇形路线，每片星岛12站，共8片；第8片6站。可前后翻地图。站点依次解锁，下一站高亮，旧存档中已完成的后续站仍可重玩，不因顺序调整丢失完成记录。
- 每个新主题6站，前2站热身、中2站运用、后2站挑战；完成主题获得阶段探索勋章。原年级勋章永久保留；年级新的全通条件是90站。
- 点击站点后星宝移动过去再进入任务；正确结算可沿地图进入下一站。完整通关当前学科的本年级，仍可6秒后自动升年级，也可取消留下复习。六年级不创建七年级。
- 新增数字结果题，支持整数、零、小数、负数及单位。键盘按任务显示小数点或负号；输入时只更新结果标签，避免每敲一位重建角色。
- 新绘制钟面、尺子、条形数量图、矩形/三角形/圆示意、正负数刻度线；保留装船、分组种植、分数铺格和选择任务。
- 选章菜单优先展示教材主题阶段，去掉每章固定3站的显示假设。非数学学科沿用原地图。

## 教材核对与内容范围

使用人教社当前六三学制电子教材入口 https://jc.pep.com.cn/ ，进入其真实阅读器核对一年级到六年级上下册的可见目录。上册电子版的现行变化已纳入，例如二上表内除法、三上混合运算/线和角、四上加法模型和乘法模型、五上图形运动及字母表示、六上生活中的负数。

这是一套按教材主题组织的原创游戏任务，不是复制教材原题或真实试卷，不等于全部单元、课时或考试考点覆盖。`verified-theme` / curriculum.verified 表示选题主题已作目录层面的核对，不表示逐题经过出版社或教师审定；部分阶段合并相关主题、只选子技能。题目数是可玩任务实例数，其中包含同一知识点的不同数字/情境练习，不是936种不同题型。

下册采用截至本轮官方入口仍展示的版本；四至六年级的下册与2026新版上册存在版本过渡。不能宣称尚未发布的2027春季新下册已经逐课同步。官方目录截图仅存 qa 供本机核对，没有作为游戏美术或复制题库发布。

## 架构

- MathCurriculum.ts：分年级、分学期主题与原创任务工厂，所有新 ID 使用 c7—c18，旧 ID 不变。
- MathRoute.ts：纯逻辑路线排序、每页12站、下一站和顺序解锁。
- Progress.ts：数学按路线选择下一任务；存档仍使用 version3，不改账号命名空间，不清空本机数据。
- MathWorkspace.ts：独立数字题工作区和辅助图形。
- Adventure.ts：地图、行走、翻页、动态站数和阶段奖励。

## 验证

TypeScript noEmit、npm test 和 Cocos Web 构建通过（qa/build-math-route.log）。测试覆盖：936个任务的基本可解性；11学科6年级；90站路线顺序、断点恢复、已完成任务重玩、6站小目标、勋章去重、数字格式、零/小数/负数、年级推进与六年级上限。与v7清单逐个比对旧任务ID、题干和解释保持一致。账号与短信宝模拟回归通过，本轮未发送短信。

实际浏览器试玩使用内存存档：
- 首图12个站点，点击未解锁第二站仍在地图，无进度奖励；第一站装2份点心后结算，并沿地图进入第二站。
- 二年级钟面题：输入1不通过、不奖励；清空后输入0通过。
- 五年级小数：按钮输入2.4，正确结算。
- 完成第一阶段最后一站：done=6，medals=1，获得“阶段探索勋章·初见星星”。
- 测试夹具完成一年级其余任务，再实际提交最后一站：gradeStatus.complete=true，勋章19枚（18章+年级）；6秒后自动进入二年级，routePage=0、chapter=6。
- 真实 starisle.adventure.v3 字符串前后相同；捕获的应用错误为空。
