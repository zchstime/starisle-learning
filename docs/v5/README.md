# 3D星宝 + 现有小岛

本版通过 Cocos 实时三维网格、标准材质、方向光、正交相机和512×512透明 RenderTexture，将立体角色嵌入原有2D界面。模型为本地程序化原创，不是图片翻转或预渲染视频。

Guardian3D.ts 包含圆润星形头部网格、立体眼睛、躯干、披风、靴子、关节式手臂与提灯。点击角色会跳跃挥手，左右拖动可查看侧面和背面。待机有轻微转头与呼吸动作。地图、任务侧栏和奖励界面使用同一角色实现。

当前采用部件关节动画，没有蒙皮骨骼、布料模拟、真实投影阴影或全场景3D。脚下为独立柔和接触阴影。后续精修可在保留渲染接口的前提下更换为美术制作的蒙皮模型。

仅启用3D和primitive模块，未加入物理模拟。角色销毁时释放独立场景节点、相机、材质、网格与渲染纹理。存档键和学科题目保持原样。

验收：TypeScript检查、既有6组领域规则以及288关卡实例测试通过。Web构建成功。浏览器拖动使模型Y轴旋转约79.7度，已观察到侧面透视与遮挡变化。地图→任务→奖励→地图流程中保持1个StarBao3DStudio，无window error。截图：qa/v5-front.png、qa/v5-side.png、qa/v5-task.png、qa/v5-final.png。

首次构建修复：将builtin-standard材质显式作为resources资产引用以生成着色器布局；按实际Web渲染校正RenderTexture方向。尚未做Android/iOS/小程序真机验证。
