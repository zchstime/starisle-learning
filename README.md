# 星屿学园 · 全学科探索

基于 **Cocos Creator 3.8.8 + TypeScript** 的可玩数学冒险原型。从小学二年级起步，现已扩展一至六年级核心主题，原创浮岛美术、向导与音效；不使用网页 UI 冒充 Cocos 游戏。

## 内容与运营后台（2026-10-28）

已新增独立后台 `/admin`：学科、题库、章节编排、Excel 导入、草稿试玩、版本发布与回退、用户查询及冻结、管理员权限和操作日志。首次启动凭据保存在 `local/admin/bootstrap.txt`，登录后请修改密码。

游戏支持启动加载和地图页定期检查发布内容；新增学科与现有玩法的新题无需重新构建。全新玩法仍需开发兼容客户端。架构、扩展方式、备份与当前范围见 [后台架构指南](docs/admin/architecture.md)。

## 运行

最方便的方式：双击根目录的 `开始试玩.command`。它会启动本机预览并打开浏览器。

1. 用 Cocos Creator 3.8.8 打开本目录。
2. 打开 `assets/scenes/StarIsle.scene`，点击编辑器预览。
3. 已构建版本：在本目录运行 `npm run serve`，访问 http://127.0.0.1:7456 。若端口已在使用，直接打开地址。
4. 重新构建：`npm run build:web`。脚本默认使用本机 `/Applications/CocosCreator-3.8.8.app`。
5. `npm test` 检查数学状态、关卡门槛、存档与测评。首次在编辑器导入后，可用本机 Cocos 附带的 TypeScript 执行 `--noEmit -p tsconfig.json`。

电脑鼠标 / 触屏点击操作。数字键盘也可输入答案。手机建议横屏。当前采用 1440 × 810 等比适配。

## v0.3 全学科体验

已增加语文、科学、道德与法治、音乐、美术、体育与健康、劳动、信息科技、综合实践，共 11 个学科入口。新增学科各有低、中、高学段的少量原创可玩样例，配中文任务朗读；音乐含真实琴音与鼓点。相邻两个年级共享学段样例，不代表每个年级独立完整内容。详情见 [v0.3 迭代说明](docs/v3/iteration.md)。

新增 81 个原创任务样例，对应 162 个年级任务实例；加原有内容共 288 个实例。词卡与选项位置每局洗牌，旧进度保留。当前英语和部分数学任务原有固定题目仍然保留。

人教版核心主题方向，尚未完成全册与 2026 最新版逐课对齐。三年级 PEP 主题已核对官方目录；其他范围与限制详见 [v0.2 架构和课程说明](docs/v2/architecture.md)。

## 架构

新模块位于 `assets/scripts/adventure`：Catalog（内容）、Puzzle（判定）、Progress（存档）、Adventure（Cocos 呈现）。旧模块保留，旧存档不覆盖。原有源码备份位于 `archive/v0.1-source.tar.gz`。

## 当前边界

项目已具备短信登录、Node 服务、可配置的 MySQL 云存档与内容后台，但不代表这些新改动已部署到生产。未配置云存储时保留本机进度；游客进度仍在浏览器/设备。尚无支付、在线班级或正式考试安全能力。挑战内容可能重复，不把重复得分宣称为掌握率。

运行与试玩以 Web 构建为准；Android / iOS / 微信小游戏仍需要各端构建、签名、SDK 适配和真机验证。课程对齐范围见 v0.2 文档，不声称完整教材覆盖。
